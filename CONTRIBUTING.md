# `json-float` Contributor's Guide

`json-float` is just a tiny convenience library, but it's made with love
and care.

Bug reports are welcome and handled on an as-available basis. Pull
requests are even better. When contributing, please honor the guarantees
at the top of the [README](./README.md), and be sure to update the
[Changelog](./CHANGELOG.md).

## Development

```
npm i
npm run build
npm test
npm run pre-commit  # Format, lint, build, and test
```

## Licensing

Please include with your submission a statement releasing it under the
MIT license.
